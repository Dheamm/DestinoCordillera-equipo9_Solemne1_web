# Destino Cordillera - Equipo 9

Repositorio: https://github.com/Dheamm/DestinoCordillera-equipo9_Solemne1_web

Sitio web de promoción turística para el destino ficticio "Destino Cordillera", desarrollado para la Solemne 01 de Desarrollo de Aplicaciones Web.

## Integrantes

- Danko Gangas
- Benjamín Herrera
- Ítalo Osorio

## Descripción

Sitio de 4 páginas que presenta un destino turístico de montaña: inicio con video de fondo, catálogo de actividades, información de hospedaje/gastronomía y formulario de reserva.

## Cómo visualizar el sitio

1. Clonar el repositorio.
2. Abrir el archivo `index.html` directamente en el navegador.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 propio (sin frameworks)
- JavaScript (menú responsive)
- No se utilizó Bootstrap
